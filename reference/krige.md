# Generic function for computing kriging forecasts

Generic function for computing kriging forecasts

## Usage

``` r
krige(x, ...)
```

## Arguments

- x:

  An **R** object.

- ...:

  Additional parameters or attributes.

## Value

Kriging results of `x`.

## Details

Refer to
[`krige.mcgf()`](https://tianxia-jia.github.io/mcgf/reference/krige.mcgf.md)
and
[`krige.mcgf_rs()`](https://tianxia-jia.github.io/mcgf/reference/krige.mcgf_rs.md)
for more details.
