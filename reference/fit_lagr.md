# Fit correlation Lagrangian models

Fit correlation Lagrangian models

## Usage

``` r
fit_lagr(x, ...)
```

## Arguments

- x:

  An **R** object.

- ...:

  Additional parameters or attributes.

## Value

A vector of estimated parameters.
