# Generic functions for calculating joint covariance/correlation matrix for mcgf objects

Generic functions for calculating joint covariance/correlation matrix
for mcgf objects

## Usage

``` r
ccov(x, ...)
```

## Arguments

- x:

  An **R** object.

- ...:

  Additional parameters or attributes.

## Value

Joint correlation/covariance matrix.

## Details

Refer to
[`ccov.mcgf()`](https://tianxia-jia.github.io/mcgf/reference/ccov.mcgf.md)
and
[`ccov.mcgf_rs()`](https://tianxia-jia.github.io/mcgf/reference/ccov.mcgf_rs.md)
for more details.
