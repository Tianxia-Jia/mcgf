# Generic function for calculating autocorrelation

Generic function for calculating autocorrelation

## Usage

``` r
acfs(x, ...)
```

## Arguments

- x:

  An **R** object.

- ...:

  Additional parameters or attributes.

## Value

A vector of mean auto-correlations for `mcgf` objects, or that plus a
list of regime-switching mean auto-correlations for `mcgf_rs` objects.

## Details

Refer to
[`acfs.mcgf()`](https://tianxia-jia.github.io/mcgf/reference/acfs.mcgf.md)
and
[`acfs.mcgf_rs()`](https://tianxia-jia.github.io/mcgf/reference/acfs.mcgf.md)
for more details.
