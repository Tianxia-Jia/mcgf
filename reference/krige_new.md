# Generic function for computing kriging forecasts for new locations

Generic function for computing kriging forecasts for new locations

## Usage

``` r
krige_new(x, ...)
```

## Arguments

- x:

  An **R** object.

- ...:

  Additional parameters or attributes.

## Value

Kriging results of `x`.

Refer to
[`krige_new.mcgf()`](https://tianxia-jia.github.io/mcgf/reference/krige_new.mcgf.md)
and
[`krige_new.mcgf_rs()`](https://tianxia-jia.github.io/mcgf/reference/krige_new.mcgf_rs.md)
for more details.
