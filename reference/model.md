# Generic function for displaying fitted models for `mcgf` objects

Generic function for displaying fitted models for `mcgf` objects

## Usage

``` r
model(x, ...)
```

## Arguments

- x:

  An **R** object.

- ...:

  Additional parameters or attributes.

## Value

Details of the fitted models.

## Details

Refer to
[`model.mcgf()`](https://tianxia-jia.github.io/mcgf/reference/model.mcgf.md)
and
[`model.mcgf_rs()`](https://tianxia-jia.github.io/mcgf/reference/model.mcgf.md)
for more details.
