# Generic function for calculating cross-correlation

Generic function for calculating cross-correlation

## Usage

``` r
ccfs(x, ...)
```

## Arguments

- x:

  An **R** object.

- ...:

  Additional parameters or attributes.

## Value

An array of cross-correlations for `mcgf` objects, or that plus a list
of regime-switching cross-correlations for `mcgf_rs` objects.

## Details

Refer to
[`ccfs.mcgf()`](https://tianxia-jia.github.io/mcgf/reference/ccfs.mcgf.md)
and
[`ccfs.mcgf_rs()`](https://tianxia-jia.github.io/mcgf/reference/ccfs.mcgf.md)
for more details.
