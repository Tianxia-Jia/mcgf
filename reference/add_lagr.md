# Generic function for adding a Lagrangian model

Generic function for adding a Lagrangian model

## Usage

``` r
add_lagr(x, ...)
```

## Arguments

- x:

  An **R** object.

- ...:

  Additional parameters or attributes.

## Value

`x` with the newly added Lagrangian model.

Refer to

[`add_lagr.mcgf_rs()`](https://tianxia-jia.github.io/mcgf/reference/add_lagr.mcgf_rs.md)
